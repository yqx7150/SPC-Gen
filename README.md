# SPC-Gen

SPC-Gen is a large-scale, physically consistent synthetic PET/CT dataset generated by a novel projection-domain latent diffusion model. It preserves the intrinsic physical correspondence between projection and image domains, covering diverse tracers, anatomical regions, disease types, and dual-tracer paired configurations.

This repository provides:
  · Full synthetic & real PET/CT data
  · Projection-domain latent diffusion generation code
  · Preprocessing & training pipelines
  · Downstream task benchmarks (segmentation, low-dose denoising, tracer separation/fusion)

Key Features
  · Projection-domain generation: Retains PET photon statistics & CT attenuation properties
  · Large-scale: 50,000+ paired projection–image slices (512×512)
  · Multi-tracer support: ¹⁸F-FDG, ¹⁸F-DOPA, ⁶⁸Ga-PSMA
  · Multi-region: Brain, abdomen, chest
  · Paired & unpaired: Single-tracer unpaired + dual-tracer paired data
  · Clinical usability: Validated on lesion segmentation, low-dose CT denoising, tracer fusion/separation
