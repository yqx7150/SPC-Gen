# SPC-Gen: Synthetic PET and CT Data using Generative Model in Projection Domain

## Introduction
In the field of nuclear medicine and medical imaging artificial intelligence, high-quality, large-scale, and physically consistent PET/CT datasets remain extremely scarce. PET imaging involves radioactive tracers, radiation exposure, high costs, and strict clinical constraints, while CT imaging is limited by radiation dose and scanner availability. Most existing generative methods for PET/CT only work in the image domain, ignoring the physical information in the projection domain, leading to anatomically plausible but physically inconsistent synthetic data, which severely limits their application in quantitative clinical analysis and high-precision AI model training.To address these challenges, we propose SPC-Gen, a large-scale synthetic PET/CT dataset generated by a projection-domain latent diffusion model. SPC-Gen explicitly preserves the physical characteristics of PET photon counting statistics and CT X-ray attenuation, maintains the intrinsic correspondence between projection domain and image domain, and covers a variety of tracers, anatomical regions, lesion types, and paired/unpaired data configurations. It provides a standardized, reusable, and physically reliable data resource for data-driven medical imaging research.This repository fully opens the SPC-Gen synthetic dataset, real clinical reference data, projection-domain generative model code, complete training and inference pipeline, and downstream task validation code, supporting one-stop reproduction, secondary development, and direct application in clinical AI scenarios.
